# Advanced Software Development

> **Hands-on laboratory exercises for the Advanced Software Development course.**

---

## Overview

This repository contains the laboratory exercises and supporting resources for the **Advanced Software Development** course.

The labs are designed to provide practical experience with modern software engineering practices, including Agentic AI, multi-model AI workflows, DevOps, software architecture, testing, Git, and deployment. Each laboratory builds on previous topics and supports the development of industry-ready software engineering skills.

---

## Repository Contents

The repository currently includes:

- Laboratory exercises
- AI Agent Configuration Guide
- Supporting documentation
- Course reference materials

## Getting Started

1. Read the **AI Agent Configuration Guide** before starting the labs.
2. Complete the laboratory exercises in numerical order.
3. Follow the instructions provided in each lab.
4. Use Git to manage and version your work.
5. Explore different AI models and workflows where appropriate.

---

## Learning Objectives

Upon completing these laboratories, students will gain practical experience in:

- Modern software engineering practices
- Agentic AI development workflows
- Multi-model AI integration
- Git and version control
- DevOps fundamentals
- Software testing and debugging
- Software architecture and design
- Professional development workflows
